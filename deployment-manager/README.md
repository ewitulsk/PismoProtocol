# Deployment Manager

This directory contains scripts to manage the initialization and configuration propagation after deploying smart contracts for different PismoSynthetics protocols.

## Supported Protocols

The deployment manager supports two protocols:

- **`perps`**: The main perpetual trading protocol with complex vault, LP, and position management
- **`oracle_builder`**: A simplified oracle management system for creating and managing price feeds

## Usage

All scripts now require a `--protocol` flag to specify which protocol to deploy or configure.

### Deployment/Initialization Scripts

#### Perps Protocol
```bash
# Development (with ts-node)
npm run dev:perps

# Production (requires npm run build first)
npm run start:perps
```

#### Oracle Builder Protocol
```bash
# Development (with ts-node)
npm run dev:oracle-builder

# Production (requires npm run build first)
npm run start:oracle-builder
```

### Configuration Copy Scripts

#### Perps Protocol
```bash
# Development (with ts-node)
npm run dev-copy:perps

# Production (requires npm run build first)
npm run copy-config:perps
```

#### Oracle Builder Protocol
```bash
# Development (with ts-node)
npm run dev-copy:oracle-builder

# Production (requires npm run build first)
npm run copy-config:oracle-builder
```

## Protocol-Specific Details

### Perps Protocol

**Input:** `contracts/deployment.json`
**Output:** `initialized_deployment.json`

**Functionality:**
1. **Reads Deployment Output:** Parses the `contracts/deployment.json` file generated by the `sui client publish` command.
2. **Connects to Sui:** Establishes a connection to the configured Sui network (e.g., 'testnet' as defined in `src/initialize.ts`).
3. **Requires Private Key:** Uses the `SUI_PRIVATE_KEY` environment variable to sign transactions.
4. **Extracts IDs:** Identifies the `Package ID`, `Global Object ID`, `Admin Cap ID`, and treasury cap IDs from the deployment output.
5. **Performs On-Chain Initialization:** Executes transaction blocks containing:
   - Adding supported LP tokens (BTC, ETH, USDC) with price feed configurations
   - Initializing LP vaults for each token pair
   - Initializing the main Program with BTC as primary collateral/position
   - Registering additional collateral tokens (ETH, USDC)
   - Registering additional position tokens (SUI, APT, SOL)
6. **Captures Details:** Extracts the `Program Object ID` and blockchain `checkpoint` number
7. **Writes Output:** Saves deployment info to `initialized_deployment.json`

**Configuration Updates:**
- `backend/config/backend_config.json`: Contract addresses and Sui API URL
- `frontend/config.toml`: Frontend environment variables
- `indexer/config/testnet.toml`: Indexer configuration with package ID and checkpoint
- `liquidation_transfer_service/config/config.toml`: Liquidation service configuration

### Oracle Builder Protocol

**Input:** `oracle_builder_contracts/deployment.json`
**Output:** `initialized_oracle_builder_deployment.json`

**Functionality:**
1. **Reads Deployment Output:** Parses the `oracle_builder_contracts/deployment.json` file
2. **Connects to Sui:** Establishes connection to Sui network
3. **Extracts IDs:** Identifies the `Package ID` and `Admin Cap ID`
4. **Captures Details:** Gets the deployment checkpoint for indexer configuration
5. **Writes Output:** Saves deployment info to `initialized_oracle_builder_deployment.json`

**Configuration Updates:**
- `oracle_builder_indexer/config/testnet.toml`: Indexer configuration with package ID and checkpoint

## Environment Variables

- `SUI_PRIVATE_KEY`: Your Sui private key (base64 encoded, potentially with `suiprivkey` prefix) used for signing transactions

## Files Generated

### Perps Protocol
- `initialized_deployment.json`: Contains packageId, globalObjectId, programObjectId, initializationCheckpoint, network, and treasury cap IDs

### Oracle Builder Protocol
- `initialized_oracle_builder_deployment.json`: Contains packageId, adminCapId, initializationCheckpoint, and network

## Development Workflow

1. **Deploy Contracts:** Use the appropriate deployment method for your protocol
2. **Run Initialization:** Execute the deployment manager with the correct protocol flag
3. **Copy Configuration:** Run the config copy script to update dependent services

Example for perps protocol:
```bash
# After deploying perps contracts
npm run dev:perps
npm run dev-copy:perps
```

Example for oracle builder:
```bash
# After deploying oracle builder contracts
npm run dev:oracle-builder
npm run dev-copy:oracle-builder
```

## Direct Command Line Usage

You can also run the scripts directly with ts-node:

```bash
# Initialize perps protocol
ts-node src/initialize.ts --protocol perps

# Initialize oracle builder
ts-node src/initialize.ts --protocol oracle_builder

# Copy perps config
ts-node src/copyConfig.ts --protocol perps

# Copy oracle builder config
ts-node src/copyConfig.ts --protocol oracle_builder
```
